# 你好，我是 okiexia-ui 👋

**把想法做成能用的小项目。**

这里记录我的 AI 工具、自动化和游戏实验。从网页阅读、新闻整理到 Minecraft 智能体，边做边学，持续折腾。

### 最近做了什么

- **[Page Lens](https://github.com/okiexia-ui/page-lens)** — 在 Chrome 侧边栏里阅读网页、向 AI 提问，支持自定义模型接口。
- **[News Agent · 新闻侠](https://github.com/okiexia-ui/news-agent)** — 把新闻整理成结构化日报，排版并导出 PDF。
- **[MC AI Agent](https://github.com/okiexia-ui/mc-ai-agent)** — 用自然语言指挥 Minecraft 机器人，由模型拆解任务并调用技能执行。

### 关注的方向

AI Agents · 实用小工具 · 工作流自动化 · 游戏实验

欢迎逛逛仓库，通过项目 Issues 交流想法、反馈问题。
